Problem and approach

The camera does not move. We never see the hidden test labels. Anything we emit that is not in the test set hurts Score A, so we only fire classes we can defend from tracks.

Learned

  • YOLOv8n, COCO open weights (Ultralytics licence)
  • ByteTrack ids on person / bicycle / car / motorcycle / bus / truck
  • No paid APIs. Weights shipped via weights/download.sh (~6 MB)

Rule-based

  • stopped_vehicle — speed ≈ 0 for ≥ 10 s, not inside a jam
  • congestion — many vehicles slow together
  • wrong_way — velocity opposite the dominant flow
  • jaywalking — person on roadway, outside crossing polygon
  • near_miss / accident — closing distance / box overlap
  • Part B — min TTC mapped so 0.5 ≈ 5 s (logistic)

Off until the layout is drawn in src/scene.json: red light, stop-line, illegal turn / U-turn, solid-line crossing, fire/smoke, failure to yield, road obstacle. Predicting them blind would add empty classes to the macro average.

Results on the sample videos

Official metric is macro F1 at tIoU 0.3 / 0.5 / 0.7. Boundaries matter more than extra classes.

After the first run_submission.py pass we will post: annotated clips, one timeline per video, the risk curve, one example of each class we fire, and failure cases (false jams, tracker ID switches).
